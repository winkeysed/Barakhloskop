# Барахлоскоп 3000

Приложение на WPF, которое сканирует диски в поисках медиафайлов и показывает случайные находки с комментариями о том, зачем вы это скачали.

Практическая польза побочная: видно, где скопилось барахло, сколько оно весит и какие папки пора разобрать.

## Что делает

- Сканирует все диски, стандартные пользовательские папки или произвольный список каталогов
- Ищет картинки (jpg, png, gif, bmp, webp, tiff, ico), аудио (mp3, wav, flac, m4a, ogg, opus, wma, aac) и видео (mp4, avi, mkv, mov, webm, wmv, flv, m4v, 3gp)
- Показывает случайный файл: картинку, видео со встроенным плеером или аудио с эквалайзером
- Генерирует вердикт по возрасту, размеру, имени файла и папке, в которой он лежит
- Считает статистику: состав по типам, топ папок по количеству файлов, общий вес
- Ведёт список всего найденного с поиском и сортировкой по размеру и дате
- Даёт открыть файл, показать его в проводнике или скопировать путь

## Требования

- Windows 10 или новее
- .NET 8 SDK для сборки, .NET 8 Desktop Runtime для запуска

## Сборка и запуск

```
cd Barakhloskop
dotnet run
```

Одиночный exe (требует установленный .NET 8 Desktop Runtime):

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ../publish
```

Автономный exe, работает без установленного .NET, около 150 МБ:

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ../publish
```

## Как работает сканер

Обход файловой системы многопоточный: каталоги лежат в общем `ConcurrentStack`, воркеры разбирают их параллельно, количество потоков равно числу ядер, но не больше восьми. Завершение определяется по счётчику простаивающих воркеров. Ошибки доступа не прерывают обход, а суммируются в счётчик и показываются в нижней полосе.

Обход домашней папки пользователя занимает около секунды на 20 тысячах каталогов. Лимит результатов — 400 тысяч файлов, после чего сканирование останавливается.

Служебные каталоги (`Windows`, `Program Files`, `AppData`, `node_modules`, `$Recycle.Bin`, кеши и подобные) пропускаются по умолчанию, иначе выдача заполняется иконками из кешей браузеров. Включаются галочкой в фильтрах. Символические ссылки не раскрываются, повторные посещения каталогов исключены.

## Ограничения

Предпросмотр использует `MediaElement`, то есть кодеки Windows Media. Форматы `mkv`, `flac`, `webm`, `opus` и подобные внутри приложения не откроются — для них показывается заглушка с кнопкой открытия во внешнем плеере. Галочка «Только то, что открывается внутри» включена по умолчанию, чтобы рулетка не предлагала такие файлы.

Для полноценного воспроизведения нужен внешний бэкенд вроде LibVLCSharp или FFmpeg. Сознательно не добавлен, чтобы не тащить десятки мегабайт зависимостей.

## Структура

```
Barakhloskop/
  Models/          MediaFile, параметры и результаты сканирования, статистика
  Services/        FileScanner, генератор вердиктов, каталог расширений, настройки
  ViewModels/      MainViewModel — вся логика окна
  Views/           MainWindow, конвертеры значений
  Themes/          Palette.xaml (цвета, типографика), Controls.xaml (шаблоны контролов)
  Infrastructure/  ObservableObject, RelayCommand, форматирование чисел и дат
```

Зависимостей за пределами .NET нет. MVVM без сторонних фреймворков.

## Настройки

Выбранные папки, фильтры и громкость сохраняются в `%AppData%\Barakhloskop\settings.json`. Файл можно удалить, приложение вернётся к настройкам по умолчанию.
